# Resaname Intelligence — فاز اول

هسته اولیه کارخانه هوشمندسازی و میز مستقل سردبیر برای رسانامه.

## آنچه این نسخه انجام می‌دهد
- اتصال فقط‌خواندنی به دیتابیس اصلی و اتصال نوشتنی به دیتابیس واسط
- واردکردن نسخه مستقل از `cards`، `theorists` و `library_resources`
- ثبت Snapshot خام و SHA-256 هر رکورد
- میز سردبیر مستقل با ورود کاربر محلی
- نمایش محتوا و وضعیت پردازش
- ساختار صف پردازش و ثبت گزارش‌ها
- Adapter قابل تنظیم برای APIهای chat-completions سازگار؛ تا زمان دریافت مستندات ISMC، فراخوانی AI عمداً غیرفعال است.
- **داسییر ساختاریافته نظریه (کارت‌ها):** ۲۲ فیلد در ۴ گروه — `Resaname\Structure\Dossier` — ذخیره در `dossier_json`.
- **داسییر ساختاریافته شخص (نظریه‌پرداز/دانشمند/مؤثر):** ۲۱ فیلد در ۵ گروه — `Resaname\Structure\PersonDossier` — ذخیره در جدول `editorial_person_dossiers`.

## داسییر ساختاریافته شخص (۲۱ فیلد / ۵ گروه)
ساختار رسمی صفحه‌ی هر نظریه‌پرداز، دانشمند و مؤثر. «تک منبع حقیقت» در `app/Structure/PersonDossier.php` است (پرامپت worker، اعتبارسنجی کلیدها و نمایش میز سردبیری همگی از همین کلاس می‌گیرند).

| گروه | فیلدها |
|---|---|
| ۱. شناسنامه و اطلاعات هویتی | `name` (نام/نام اصلی/جایگزین‌ها/نگارش‌ها) · `basic_info` (تصویر، تولد/وفات، ملیت، کشور) · `introduction` (معرفی ۲۰۰–۲۵۰ کلمه‌ای) · `specializations` (رشته اصلی/فرعی، زمینه‌های پژوهشی، تخصص‌ها) · `affiliations` (دانشگاه‌ها، مراکز پژوهشی، مؤسسات و انجمن‌ها) |
| ۲. زندگی‌نامه و مسیر علمی | `education` (تحصیلات، مدارک، استادان، زمینه خانوادگی) · `career` (تدریس، موقعیت‌ها، مسئولیت‌ها، فعالیت‌ها، مراکز) · `historical_context` · `intellectual_evolution` · `students_and_influences` |
| ۳. اندیشه‌ها و دستاوردها (هسته صفحه) | `thought_system` · `theories` (با لینک درون‌سایتی) · `key_concepts` · `works` (کتاب/مقاله/آثار شاخص/سخنرانی/ترجمه) · `method` (با لینک) · `legacy` (با لینک) |
| ۴. نقد و ارزیابی علمی | `critiques` (با لینک به موافق/مخالف/منتقد) · `responses` · `standing` |
| ۵. ارتباطات و منابع علمی | `network` (هم‌عصران، استاد/شاگرد، هم‌فکر/منتقد، مکاتب، نظریه‌ها، مراکز — با لینک) · `references` (حداقل ۵ منبع فارسی/انگلیسی، DOI/لینک ناشر) |

قوانین ملزم برای AI:
- **هر ۲۱ کلید باید در خروجی حضور داشته باشد** (حذف/اضافه/تغییر نام ممنوع؛ در غیر این صورت کل داسییر رد می‌شود).
- **هیچ فکتی اختراع نمی‌شود:** فیلد بدون داده‌ی مطمئن، خالی می‌ماند و در `editorial_issues` به‌عنوان «نیازمند پژوهش عمیق» گزارش می‌شود.
- **لینک‌های درون‌سایتی** فقط با قالب‌های `https://resaname.ir/cards/{slug}`، `/theorists/{slug}`، `/resources/{slug}` و فقط از slugهای فهرست «محتوای سایت» که worker در هر اجرا از دیتابیس اصلی می‌سازد.

اجرا:
- کل: دکمه‌ی «👤 ساخت داسییر نظریه‌پردازان و دانشمندان» در صفحه‌ی تنظیمات (همه‌ی سندهای `theorists` را به صف `person_dossier` می‌افزاید).
- تک‌مورد: دکمه‌ی «👤 ساخت داسییر ساختاریافته» در صفحه‌ی بررسی هر نظریه‌پرداز.
- worker هر کار `person_dossier` را پردازش می‌کند؛ نتیجه با درصد تکمیل و وضعیت در `editorial_person_dossiers` ذخیره و در صفحه‌ی بررسی نمایش داده می‌شود.

## فاز ۲ — هسته دانش علمی (گراف دانش)

گراف دانش ساختاریافته برای دانشنامه‌ی علمی: ۲۸ نوع موجودیت، ۲۰ نوع رابطه، ۹ بُعد فاکت؛
۵۸۱ موجودیت و ۳۷۵ رابطه seed شده (دو نظام مستقل: فکری-نظری و روش‌شناختی).

- جداول `kb_*` (۸ جدول) در دیتابیس `resaname_editorial` — DDL: `database/kb_schema.sql`
- ثبت‌نام‌سازها (تک منبع حقیقت): `app/Knowledge/{EntityTypes,RelationTypes,FacetTypes}.php`
- سرویس PHP مرجع: `app/Knowledge/KnowledgeBase.php`
- خط فرمان (۱۶ دستور): `php bin/kb.php help`
- سرور MCP (۱۳ ابزار): `mcp/resaname-kb/server.mjs`
- ابزارهای OpenCode: Skill + ایجنت `kb-curator` + پلاگین `/kb` در `.opencode/`
- مستندات کامل: `docs/knowledge-core.md`

شروع سریع:
1. `php bin/kb.php install` (اگر جداول ساخته نشده‌اند)
2. `php bin/kb.php seed` (آیدامپوتنت)
3. `php bin/kb.php status` و `php bin/kb.php validate`

## پیش‌نیاز
- PHP 8.2+
- PDO MySQL
- cURL
- MariaDB/MySQL
- HTTPS فعال

## نصب
1. یک دیتابیس خالی جداگانه بسازید؛ مثلاً `resaname_editorial`.
2. پوشه پروژه را خارج از `public_html` قرار دهید. فقط پوشه `public` باید در دسترس وب باشد.
3. `composer install --no-dev` را اجرا کنید.
4. `.env.example` را به `.env` کپی و مقادیر را تکمیل کنید.
5. دیتابیس واسط را با دستور زیر بسازید:
   `php bin/migrate.php`
6. کاربر سردبیر اولیه را بسازید:
   `php bin/create-editor.php`
7. همگام‌سازی اولیه را اجرا کنید:
   `php bin/sync.php --all`
8. DocumentRoot دامنه/ساب‌دامنه میز سردبیر را روی پوشه `public` تنظیم کنید.
9. در Cron هاست، هر 5 دقیقه اجرا کنید:
   `php /ABSOLUTE/PATH/resaname-intelligence/bin/worker.php`

## نکات امنیتی
- دسترسی دیتابیس اصلی را با کاربر SELECT-only بسازید.
- دسترسی نوشتن فقط برای دیتابیس واسط باشد.
- `.env` و `storage` نباید از وب قابل دسترسی باشند.
- فعلاً هیچ مسیر انتشار به دیتابیس اصلی فعال نیست.
- این نسخه برای تست محدود و بازبینی فنی است؛ قبل از بهره‌برداری عمومی باید HTTPS، محدودیت تلاش ورود، پشتیبان‌گیری و بررسی امنیتی هاست تأیید شود.

## محدودیت اتصال AI
آدرس `https://ai.ismc.ir/api` و نام مدل‌ها به‌تنهایی قرارداد API را مشخص نمی‌کنند. برای فعال‌سازی، مسیر دقیق endpoint، شکل احراز هویت، payload و نمونه پاسخ موفق/خطا لازم است. هیچ کلید واقعی را در چت یا Git قرار ندهید.
